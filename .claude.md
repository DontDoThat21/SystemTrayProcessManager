## Project Identity

**Version**: 0.1.0-alpha  
**Type**: WPF Desktop Application  
**Target Framework**: .NET 8.0  
**Language**: C# 12

## Project Description
A sophisticated Windows system tray application for process management with global hotkeys, per-process audio control, and advanced window manipulation. Built as a portfolio piece demonstrating mastery of Windows API integration, modern C# patterns (MVVM, DI, async/await), and professional WPF development.

## Project Goals
1. **Technical Excellence**: Showcase advanced Windows programming skills
2. **Clean Architecture**: Demonstrate MVVM, dependency injection, and separation of concerns
3. **Portfolio Quality**: Production-ready code with comprehensive documentation
4. **User Experience**: Intuitive UI with smooth animations and responsive controls
5. **Performance**: <50ms hotkey response, <2s startup, <50MB memory footprint

## Core Principles

### 1. Code Quality Standards
- **XML Documentation**: All public APIs must have XML comments
- **Error Handling**: Try-catch with comprehensive logging on all operations
- **Async First**: All I/O operations must be async (Task/async-await)
- **Resource Management**: Proper disposal of unmanaged resources (IDisposable)
- **Null Safety**: Null checks on all dependencies

### 2. Architecture Principles
- **SOLID**: Single responsibility, interface-based design
- **DRY**: Don't repeat yourself
- **Separation of Concerns**: Core → Infrastructure → UI layers
- **Dependency Injection**: Constructor injection throughout
- **Testability**: Design for unit testing

### 3. Performance Requirements
- **Startup Time**: < 2 seconds from launch to tray icon
- **Memory Usage**: < 50 MB at idle
- **CPU Usage**: < 1% at idle
- **Hotkey Response**: < 50ms from keypress to action execution
- **Process Polling**: 5-second intervals (not real-time)

### 4. Security Considerations
- **UAC Awareness**: Detect and prompt for elevation when needed
- **Safe P/Invoke**: Always use SafeHandle for unmanaged resources
- **Input Validation**: Validate all user input and configuration files
- **Graceful Degradation**: Handle denied permissions gracefully

## Known Challenges & Solutions

### Challenge 1: Global Hotkeys with GC
**Problem**: Delegate for keyboard hook gets garbage collected  
**Solution**: Store delegate as class field, never as local variable

### Challenge 2: Hotkey Response Time
**Problem**: Slow response if action executed in hook callback  
**Solution**: Execute actions on ThreadPool asynchronously

### Challenge 3: UAC and Protected Processes
**Problem**: Can't manipulate elevated processes from non-elevated app  
**Solution**: Detect elevation, prompt user, handle gracefully

### Challenge 4: Audio Session Enumeration
**Problem**: COM objects need proper disposal  
**Solution**: Use IDisposable pattern, dispose in finally blocks

### Challenge 5: Process Window Handles
**Problem**: Window handles become invalid when process closes  
**Solution**: Validate handles before use, handle exceptions gracefully

## Critical Implementation Notes

### ⚠️ Global Hotkey Hook
- **MUST** store delegate reference to prevent GC
- **MUST** unhook in Dispose method
- **MUST** execute actions outside hook callback
- **NEVER** block in hook callback (causes input lag)

### ⚠️ Windows API P/Invoke
- **ALWAYS** use `SetLastError = true` for debugging
- **ALWAYS** check return values and use `Marshal.GetLastWin32Error()`
- **ALWAYS** use `internal` visibility, not `public`
- **PREFER** SafeHandle over IntPtr for unmanaged resources

### ⚠️ Audio Control with NAudio
- **MUST** dispose of MMDeviceEnumerator and MMDevice
- **MUST** handle audio device disconnection
- **MUST** handle missing audio sessions gracefully
- **REMEMBER** COM objects need explicit disposal

### ⚠️ MVVM with CommunityToolkit
- **USE** [ObservableProperty] for properties
- **USE** [RelayCommand] for commands
- **INJECT** services via constructor
- **NOTIFY** command CanExecute changes when state changes

## File Naming Conventions

### C# Files
- **Interfaces**: `IServiceName.cs` (e.g., `IProcessService.cs`)
- **Services**: `ServiceNameService.cs` (e.g., `ProcessMonitorService.cs`)
- **Models**: `ModelName.cs` (e.g., `ProcessInfo.cs`)
- **ViewModels**: `ViewNameViewModel.cs` (e.g., `MainViewModel.cs`)
- **Views**: `ViewName.xaml` (e.g., `MainWindow.xaml`)
- **Enums**: `EnumName.cs` (e.g., `ProcessActionType.cs`)

### XAML Files
- **Windows**: `WindowName.xaml` (e.g., `SettingsWindow.xaml`)
- **Controls**: `ControlName.xaml` (e.g., `HotkeyCaptureBox.xaml`)
- **Styles**: `ElementStyles.xaml` (e.g., `ButtonStyles.xaml`)
- **Themes**: `ThemeName.xaml` (e.g., `DarkTheme.xaml`)
